Giai đoạn 1: Tối ưu macOS System & UX nền tảng

Xoá bỏ độ trễ bàn phím, kích hoạt góc nhìn chuẩn lập trình trong Finder và cử chỉ Trackpad nhanh.

Hệ thống

1.1. Tăng tốc độ bàn phím & Tắt menu giữ phím Apple

Bắt buộc cho dân code/Vim/Cursor: Giảm thời gian chờ trước khi lặp phím và tăng tốc độ lặp lại lên mức tối đa. 

# Set ultrafast key repeat rate and low initial delay
defaults write -g InitialKeyRepeat -int 15
defaults write -g KeyRepeat -int 2

# Disable press-and-hold popup in favor of real key repeating
defaults write -g ApplePressAndHoldEnabled -bool false

# Disable automatic period substitution on double-space
defaults write -g NSAutomaticPeriodSubstitutionEnabled -bool false

1.2. Cử chỉ Trackpad & Chạm để nhấp (Tap to Click)

Bật chạm nhẹ để click không cần nhấn lún, tăng tốc độ rê chuột và cử chỉ chuyển desktop. 

# Enable Tap-to-click on built-in and Bluetooth Trackpads
defaults write com.apple.driver.AppleBluetoothMultitouch.trackpad Clicking -bool true
defaults write com.apple.AppleMultitouchTrackpad Clicking -bool true
defaults -currentHost write NSGlobalDomain com.apple.mouse.tapBehavior -int 1
defaults write NSGlobalDomain com.apple.mouse.tapBehavior -int 1

# Increase mouse/trackpad speed
defaults write NSGlobalDomain com.apple.trackpad.scaling -float 3.0

1.3. Tối ưu Finder chuẩn Lập trình viên

Luôn hiện đuôi file, thanh đường dẫn, thanh trạng thái, gom folder lên đầu và chặn rác file .DS_Store. 

# Always show all file extensions
defaults write NSGlobalDomain AppleShowAllExtensions -bool true

# Show Path bar and Status bar
defaults write com.apple.finder ShowPathbar -bool true
defaults write com.apple.finder ShowStatusBar -bool true

# Keep folders on top when sorting by name
defaults write com.apple.finder _FXSortFoldersFirst -bool true

# Prevent .DS_Store file creation on USB and Network volumes
defaults write com.apple.desktopservices DSDontWriteNetworkStores -bool true
defaults write com.apple.desktopservices DSDontWriteUSBStores -bool true

# Apply changes by restarting Finder
killall Finder

Tính năng Pro: Trích xuất & Khôi phục Setting máy Mac hiện tại

Tự động hóa

Bạn muốn lưu lại toàn bộ các thiết lập cử chỉ Trackpad, tốc độ bàn phím, cấu hình Finder và Dock hiện tại của máy bạn thành 1 file script để sau này dùng cho máy mới? Hãy dùng công cụ xuất tự động dưới đây.

1 Bước 1: Trích xuất Setting

Chạy script để tự động đọc các thiết lập bạn đang dùng trên máy này.

2 Bước 2: Lưu vào `backups/`

File khôi phục được sinh ra gọn gàng trong thư mục `backups/` để bạn lưu trữ.

3 Bước 3: Khôi phục 1-Click

Khi sang máy Mac mới, chỉ cần chạy file backup là mọi thiết lập tự động áp dụng 100%.

File script trong dự án: scripts/export-macos-settings.vi.sh

Chạy lệnh này trên máy Mac hiện tại để trích xuất setting: 

bash scripts/export-macos-settings.vi.sh

File khôi phục được tạo tại: backups/apply-my-settings.vi.sh

Khi cài máy Mac mới, chỉ cần copy file này sang và chạy: 

bash backups/apply-my-settings.vi.sh

CLI & Công cụ

2.3. Bộ công cụ CLI Thế hệ mới (Tuỳ chọn)

Tick chọn hoặc bỏ chọn các công cụ bạn muốn. Mỗi tool thay thế một lệnh Unix cũ với tốc độ nhanh gấp 10-50 lần.

Đã chọn 9/9 công cụ
eza Thay thế `ls`

Là gì: Trình duyệt danh sách file/thư mục viết bằng Rust, hiển thị icon, màu sắc phân quyền, xem cây thư mục lồng nhau (`--tree`).

Tại sao: Hiển thị ngay trạng thái Git của từng file (đã sửa, chưa track) và màu sắc trực quan, không bị đơn điệu như lệnh `ls` cũ.

bat Thay thế `cat`

Là gì: Trình đọc nội dung file trong terminal với tính năng tô màu cú pháp theo từng ngôn ngữ (JS, Python, Rust...).

Tại sao: Hiển thị số dòng rõ ràng, vạch chỉ báo thay đổi Git diff ở lề trái, đọc code nhanh không cần mở editor.

ripgrep (rg) Thay thế `grep`

Là gì: Công cụ tìm kiếm chuỗi / regex trong toàn bộ repo với tốc độ nhanh nhất thế giới.

Tại sao: Tự động bỏ qua các folder rác (node_modules, .git) theo .gitignore, tìm code trong repo triệu dòng chỉ mất vài mili-giây.

fzf Tìm kiếm mờ

Là gì: Bộ lọc tìm kiếm mờ (Fuzzy finder) đa năng cho file, lịch sử lệnh terminal, git branch.

Tại sao: Nhấn `Ctrl + R` để tìm lại bất kỳ câu lệnh nào từng gõ chỉ với vài ký tự không cần nhớ chính xác toàn bộ.

zoxide (z) Thay thế `cd`

Là gì: Công cụ điều hướng thông minh tự nhớ các thư mục bạn hay làm việc.

Tại sao: Chỉ cần gõ `z tên_dự_án` là nhảy ngay vào thư mục làm việc, tiết kiệm hàng trăm lần gõ đường dẫn dài mỗi ngày.

gh (GitHub CLI) GitHub CLI

Là gì: Công cụ dòng lệnh chính thức của GitHub giúp quản lý repo, Pull Request, Issue, CI/CD Actions.

Tại sao: Tạo PR (`gh pr create`), clone repo (`gh repo clone`) và đăng nhập GitHub một chạm không cần copy SSH key thủ công.

tldr Sổ tay lệnh

Là gì: Tra cứu hướng dẫn ngắn gọn cho mọi lệnh terminal kèm ví dụ thực tế dễ hiểu.

Tại sao: Thay vì đọc tài liệu dài hàng nghìn dòng của lệnh `man`, `tldr tar` chỉ cho bạn đúng 3 ví dụ thực chiến cần dùng.

jq Xử lý JSON

Là gì: Bộ xử lý, định dạng đẹp và trích xuất dữ liệu JSON từ API/terminal.

Tại sao: Định dạng kết quả `curl` JSON rõ ràng, trích xuất nhanh trường dữ liệu mà không cần viết script riêng.

yq Xử lý YAML

Là gì: Trình xử lý dữ liệu YAML, XML, CSV trực tiếp trên dòng lệnh.

Tại sao: Cực kỳ tiện lợi khi chỉnh sửa file Docker Compose, Kubernetes và GitHub Actions workflow tự động.

Lệnh cài đặt Homebrew tự động cập nhật: 
brew install eza bat ripgrep fzf zoxide gh tldr jq yq

2.4. Cấu hình Aliases & Tích hợp Shell (`.zshrc`)

Tự động kích hoạt các công cụ mới khi gõ các lệnh quen thuộc và nạp phím tắt cho Zoxide/FZF. 

# Append smart aliases and tool completions to ~/.zshrc
cat << 'EOF' >> ~/.zshrc

# --- Modern CLI Aliases ---
alias ls="eza --icons --group-directories-first"
alias ll="eza -la --icons --group-directories-first --git"
alias lt="eza --tree --level=2 --icons"
alias cat="bat --paging=never"
alias grep="rg"

# --- Zoxide (Smarter `cd`) & FZF Setup ---
eval "$(zoxide init zsh)"
source <(fzf --zsh)
EOF

# Apply changes to current terminal session
source ~/.zshrc

cat << 'EOF' > .cursorrules
# Engineering Standards & Load-Bearing Invariants

## 1. Core Philosophy
- Correctness first, then maintainability 6 months out.
- Apply taste: delete weightless code, refuse needless abstractions, prefer boring and robust designs.
- Zero code bloat: Never avoidably allocate, copy, or compute. Delete dead imports and obsolete helpers immediately.

## 2. Strict Type System & Architecture
- Strict TypeScript: Absolute prohibition of `any` or loose type assertions (`as unknown as T`). Explicit return types on all exported functions.
- Single source of truth: Schema validation (Zod) -> infer TypeScript types directly.

## 3. Surgical Edits & Git Integrity
- Never touch unrelated lines or format files arbitrarily outside the requested prompt scope.
- Before editing exported symbols, check all callsites to prevent silent regressions.
- Commit messages MUST adhere to Conventional Commits: `feat(scope): ...`, `fix(scope): ...`, `refactor(scope): ...`.

## 4. Verification & Testing Deliverable
- Never claim a task is "done" without concrete verification proof:
  - Run the specific test file or smoke test command covering the changed logic.
  - Report exact test output and edge cases covered.
EOF
