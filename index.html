Tối ưu Hệ thống & Trải nghiệm macOS

Đã duyệt

1.1. Tăng tốc độ Lặp phím & Tắt giữ phím hiện dấu

Cho phép giữ phím để lặp ký tự siêu nhanh và tắt popup dấu tiếng Anh của Apple (rất cần thiết khi dùng phím Vim trong editor). 

# Set ultrafast key repeat rate (Delay until repeat: 15, Key repeat rate: 2)
defaults write -g InitialKeyRepeat -int 15
defaults write -g KeyRepeat -int 2

# Disable press-and-hold popup in favor of real key repeating
defaults write -g ApplePressAndHoldEnabled -bool false

# Disable automatic period substitution on double-space
defaults write -g NSAutomaticPeriodSubstitutionEnabled -bool false

1.2. Cử chỉ Trackpad & Chạm để nhấp (Tap to Click)

Bật chạm để nhấp nhẹ nhàng thay vì phải nhấn lún Trackpad xuống. 

# Enable "Tap to click" for built-in & Bluetooth trackpad
defaults write com.apple.driver.AppleBluetoothMultitouch.trackpad Clicking -bool true
defaults write com.apple.AppleMultitouchTrackpad Clicking -bool true
defaults -currentHost write NSGlobalDomain com.apple.mouse.tapBehavior -int 1
defaults write NSGlobalDomain com.apple.mouse.tapBehavior -int 1

1.3. Tối ưu Finder cho Lập trình viên

Hiển thị rõ đuôi file (.ts, .env, .json), thanh đường dẫn, thanh trạng thái và giữ thư mục trên đầu. 

# Always show all file extensions
defaults write NSGlobalDomain AppleShowAllExtensions -bool true

# Show Path bar and Status bar
defaults write com.apple.finder ShowPathbar -bool true
defaults write com.apple.finder ShowStatusBar -bool true

# Keep folders on top when sorting by name
defaults write com.apple.finder _FXSortFoldersFirst -bool true

# Avoid creating .DS_Store files on network or USB volumes
defaults write com.apple.desktopservices DSDontWriteNetworkStores -bool true
defaults write com.apple.desktopservices DSDontWriteUSBStores -bool true

# Restart Finder to apply
killall Finder

Tính năng Pro: Trích xuất & Khôi phục Setting máy Mac hiện tại

Tự động hóa

Trích xuất toàn bộ cử chỉ vuốt 4 ngón trackpad, nhấp 2 ngón, tốc độ phím, độ nhạy chuột, Finder và Dock hiện tại của bạn thành một script độc lập. Khi sang máy Mac mới, chỉ cần chạy script này để khôi phục toàn bộ trong 2 giây mà không cần chỉnh tay từng mục.

1 Trích xuất Setting

Chạy script để quét cấu hình trên máy hiện tại:

bash scripts/export-macos-settings.vi.sh
scripts/export-macos-settings.vi.sh
2 Vị trí lưu file

Script tự động tạo file khôi phục tại thư mục:

backups/apply-my-settings.vi.sh

Lưu file này vào iCloud Drive, USB hoặc kho Git cá nhân.

3 Khôi phục trên máy mới

Chạy lệnh trên máy Mac mới để khôi phục:

bash backups/apply-my-settings.vi.sh

Có hiệu lực ngay: tự khởi động lại Finder & Dock

Trình quản lý Gói & Bộ CLI Hiện đại

Đã duyệt

2.1. Xcode Command Line Tools & Homebrew

Bộ biên dịch C/C++ bắt buộc của Apple và trình quản lý gói phần mềm tiêu chuẩn cho macOS Apple Silicon.

Apple Developer (Xcode CLT) Homebrew Official (brew.sh) 
# 1. Install Apple Xcode Command Line Tools
xcode-select --install

# 2. Install Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 3. Configure Homebrew PATH for Apple Silicon (~/opt/homebrew)
(echo; echo 'eval "$(/opt/homebrew/bin/brew shellenv)"') >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

2.2. Shell Prompt Siêu tốc: Starship (Rust)

Prompt terminal cực nhẹ, hiển thị tức thời nhánh Git, thay đổi file, thời gian chạy lệnh và phiên bản runtime hiện tại.

Starship Official Website 
# Install Starship via Homebrew
brew install starship

# Activate Starship in your ~/.zshrc
echo 'eval "$(starship init zsh)"' >> ~/.zshrc

2.3. Bộ Công cụ CLI Thế hệ mới Siêu tốc (Rust/Go)

Nhấp vào ô chọn của từng công cụ để bật/tắt. Câu lệnh cài đặt bên dưới sẽ tự động cập nhật theo thời gian thực.

eza Thay thế `ls`

Là gì: Trình duyệt danh sách file/thư mục viết bằng Rust, hiển thị icon, màu sắc phân quyền, xem cây thư mục lồng nhau (`--tree`).

Tại sao dùng: Hiển thị ngay trạng thái Git (file nào vừa sửa, chưa commit) trực tiếp bên cạnh tên file và phân biệt rõ định dạng file.

bat Thay thế `cat`

Là gì: Bộ đọc file thay thế `cat`, tự động tô màu cú pháp theo ngôn ngữ, đánh số dòng và tích hợp Git diff.

Tại sao dùng: Xem nhanh file code, json, yaml trực tiếp trong Terminal mà không cần mở Editor, hiển thị rõ dấu `+` xanh / `-` đỏ của Git.

ripgrep (`rg`) Thay thế `grep`

Là gì: Công cụ tìm kiếm chuỗi văn bản và Regex nhanh nhất thế giới hiện nay, tự động bỏ qua file trong `.gitignore`.

Tại sao dùng: Tìm kiếm từ khóa xuyên suốt repo lớn hàng triệu dòng code trong vài mili-giây, không bị quét vào thư mục `node_modules` hay `.git`.

fzf Tìm kiếm mờ

Là gì: Bộ tìm kiếm mờ tương tác cho Terminal (cho phép gõ vài ký tự ngẫu nhiên để tìm chính xác file, branch, commit).

Tại sao dùng: Nhấn `Ctrl + R` để tìm lại mọi lệnh dài từng gõ trong tích tắc; giảm 90% thời gian gõ phím.

zoxide (`z`) Thay thế `cd`

Là gì: Lệnh chuyển thư mục thông minh, tự động học và nhớ các thư mục bạn hay làm việc.

Tại sao dùng: Thay vì phải gõ đường dẫn dài `cd ~/Documents/git/setup-dev-mac`, bạn chỉ cần gõ `z setup` là nhảy ngay tới project.

gh (GitHub CLI) GitHub CLI

Là gì: Công cụ dòng lệnh chính thức của GitHub giúp quản lý repo, Pull Request, Issue, CI/CD Actions.

Tại sao dùng: Tạo Pull Request, clone repo, cấu hình SSH keys và duyệt code trực tiếp trong Terminal mà không cần mở trình duyệt web.

tldr Sổ tay lệnh

Là gì: Sổ tay tra cứu lệnh ngắn gọn, tập trung vào các ví dụ thực chiến hay dùng nhất thay vì đọc trang `man` dài dòng.

Tại sao dùng: Xem ngay 4-5 ví dụ thực tế cho các lệnh khó nhớ như `tar`, `ffmpeg`, `docker`, `curl` chỉ trong 1 giây.

jq & yq Xử lý JSON/YAML

Là gì: Bộ đôi công cụ xử lý, lọc trường dữ liệu, format màu cho file JSON và YAML.

Tại sao dùng: Tra cứu nhanh trường dữ liệu từ API response, đọc package.json, và xử lý cấu hình Docker Compose / Kubernetes.

Lệnh cài đặt tùy chỉnh (Tự động cập nhật theo các tool bạn chọn ở trên) 8 packages selected 
brew install eza bat ripgrep fzf zoxide gh tldr jq yq

2.4. Cấu hình Aliases & Tích hợp Shell (`.zshrc`)

Tự động kích hoạt các công cụ mới khi gõ các lệnh quen thuộc và nạp phím tắt cho Zoxide/FZF. 

# Append modern CLI aliases and integrations to ~/.zshrc
cat << 'EOF' >> ~/.zshrc

# --- Modern CLI Aliases ---
alias ls="eza --icons --group-directories-first"
alias ll="eza -la --icons --group-directories-first --git"
alias lt="eza --tree --level=2 --icons"
alias cat="bat --paging=never"
alias grep="rg"

# --- Zoxide & FZF Integrations ---
eval "$(zoxide init zsh)"
source <(fzf --zsh)
EOF

# Reload shell config
source ~/.zshrc

Trình quản lý Runtime & Đóng gói Container

Đã duyệt

3.1. Quản lý Đa phiên bản Ngôn ngữ: `mise` (Thay thế nvm, pyenv, rbenv)

Công cụ quản lý đa phiên bản ngôn ngữ viết bằng Rust, khởi động terminal nhanh hơn 20x so với `nvm`, tự động chuyển version khi cd vào thư mục project.

mise Official Docs (mise.jdx.dev) 
# Install mise via Homebrew
brew install mise

# Activate mise in your ~/.zshrc
echo 'eval "$(mise activate zsh)"' >> ~/.zshrc
source ~/.zshrc

# Install and activate global Node.js LTS
mise use --global node@lts

3.2. Toolchain JavaScript / TypeScript Siêu tốc: `bun` & `pnpm`

Bun chạy trực tiếp TypeScript không cần build trước; pnpm tiết kiệm hàng chục GB ổ cứng nhờ cơ chế hard link giữa các dự án.

Bun Official (bun.sh) pnpm Official (pnpm.io) 
# Install Bun (All-in-one JS/TS runtime & package manager)
curl -fsSL https://bun.sh/install | bash

# Install pnpm via Homebrew
brew install pnpm

3.3. Python Thế hệ mới: `uv` (Nhanh hơn pip 10-100 lần)

Thay thế hoàn toàn `pip`, `poetry`, `virtualenv`. Quản lý môi trường ảo và cài đặt thư viện Python trong tích tắc.

Astral uv Documentation 
# Install uv via Homebrew
brew install uv

# Example: Create virtualenv and run script at lightning speed
# uv venv && source .venv/bin/activate
# uv pip install fastapi uvicorn

3.4. Chạy Docker & Linux VM Siêu nhẹ: `OrbStack`

Khởi động trong 2 giây, tốn ít hơn 80% RAM so với Docker Desktop, gần như 0% CPU khi idle, tương thích 100% với lệnh docker và docker-compose.

OrbStack Official (orbstack.dev) 
# Install OrbStack (Lightweight Docker & Linux VM engine)
brew install --cask orbstack
